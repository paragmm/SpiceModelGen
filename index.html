How to Read a Datasheet

Extracting parameters from a BJT datasheet can be tricky. Here is a guide on where to look for each value in standard NPN/PNP datasheets.

Model Identity
Parameter Meaning & Purpose Where to find it
Model Name The name of your SPICE model (e.g. BC847B). Used in the .model statement. The title or part number on the front page.
Type Polarity: NPN or PNP. Top description (e.g. "NPN General Purpose Amplifier").
Datasheet Values
Parameter Meaning Datasheet Section
VCEO Collector-Emitter Breakdown Voltage Absolute Maximum Ratings table. Look for VCEO.
IC Continuous Collector Current Absolute Maximum Ratings table. Look for IC.
hFE (min / max) DC Current Gain Electrical Characteristics -> On Characteristics. Read at the typical operating IC (e.g. 2mA).
fT Transition Frequency / Current-Gain Bandwidth Electrical Characteristics -> Small-Signal Characteristics.
VBE(on) Base-Emitter Turn-on Voltage On Characteristics. Often given as a max value, typical is ~650-700mV.
VCE(sat) Collector-Emitter Saturation Voltage On Characteristics. Important for switching applications.
Cob / Cib Output / Input Capacitance Small-Signal Characteristics. Often measured at specific voltages like VCB=10V.
ICBO Collector Cut-off Current Off Characteristics. Leakage current.
SPICE Gummel-Poon Parameters

These are the core underlying SPICE parameters that the engine calculates. You can manually tweak them before saving.

Parameter Meaning Good Practice / Notes
BFForward BetaDerived from typical hFE. Core parameter for DC analysis.
ISTransport Saturation CurrentUsually 1e-15 to 1e-12 A. Affects VBE drop.
VAFForward Early VoltageLower values (20-50V) mean steeper IC curve slope in active region.
IKFHigh-Current Roll-offDerived from datasheet hFE vs IC curve. Critical for high-current accuracy.
NFForward Emission CoeffAlmost always ~1.0 for Silicon BJTs.
NRReverse Emission CoeffUsually ~1.0.
BRReverse BetaUsually very low (0.1 to 10). Affects saturation region characteristics.
TFForward Transit TimeSets fT limit. TF = 1 / (2 * π * fT). Vital for transient analysis.
TRReverse Transit TimeTypically much larger than TF (10x-100x). Dominates storage time in switching.
CJCB-C Zero-Bias CapDerived from Cob. Crucial for AC/RF behavior.
CJEB-E Zero-Bias CapDerived from Cib. Affects input impedance at high frequencies.
VJEB-E Built-in PotentialTypically 0.7V to 0.75V for Silicon.
MJEB-E Grading CoeffTypically 0.33 (graded) to 0.5 (abrupt).
EGEnergy Gap1.11eV for Silicon. Change only if using Germanium (0.67).
XTIIS Temp ExponentDefault 3 for BJTs. Affects thermal stability simulations.
XTBBF Temp ExponentValues between 1.0 and 2.0. Vital for temperature sweeps.
RBBase Resistance10 to 200 ohms typical. Affects high-frequency gain and noise.
REEmitter ResistanceUsually <1 ohm. Heavily degrades high-current gain.
RCCollector ResistanceSets VCE(sat) limits. Typically 0.1 to 5 ohms.
IRBRB Roll-off CurrentCurrent where RB falls halfway to RBM. Models base conductivity modulation.
RBMMin Base ResistanceRB at very high currents. Usually roughly half of RB.
XTFTF Bias DependenceControls fT roll-off with VBC. Fine-tunes high-frequency response.
VTFTF Voltage DependenceVoltage parameter for TF bias.
ITFTF Current DependenceCurrent parameter for TF bias. Modifies fT roll-off at high currents.
VJCB-C Built-in PotentialTypically 0.5V to 0.75V.
MJCB-C Grading CoeffTypically 0.33 for graded junctions.
